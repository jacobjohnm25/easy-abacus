# Easy Abacus

Two installable, offline-ready calculator apps that share one theme system and one saved-settings store.

- **Live Tape Calculator** (`/`): a simple calculator with a live display and history
- **Job Site Calculator** (`/job-site/`): trade calculators for concrete, bricks, lumber, stairs, drain fall, pipe volume, tiles, squaring and unit conversion, in imperial or metric

## Live Tape Calculator

A simple calculator that shows the calculation and its result live as you type.

- Live expression and result, with the most recent calculation on top
- History modal with the 20 most recent calculations; tap one to add its result
- Themes: system/light/dark mode, accent colors, custom background and text colors with a WCAG contrast check
- History and theme save to local storage; "Restore default settings" resets them
- Keyboard support, screen reader announcements, reduced motion support
- Installable progressive web app that works offline

## Job Site Calculator

- Concrete (slab, footing or column, with premix bags), bricks and blocks, board feet, stairs, drain pipe fall, water in a pipe, tiles and flooring, square and diagonal, unit converter
- Imperial or metric; fractions like `1 1/2` work and lengths show to the nearest 1/16″
- Each result shows how it was worked out and can be copied
- Remembers your tool, units and measurements; links like `job-site/#stairs` open a tool directly
- Responsive from 280 px phones to wide desktops, with a swipeable tool strip on phones

## Shared theme and storage

Both apps use the modules in `shared/`:

- `shared/storage.js`: one local storage namespace (`easyAbacus:<app>:<name>`, plus `easyAbacus:shared:*`), safe when storage is blocked, with cross-tab updates and migration of older keys
- `shared/theme.js` and `shared/theme.css`: light, dark or system mode (shared by every app), accent colors, custom background and text colors, a live WCAG contrast check, and restore defaults

Each app saves its settings, theme and last calculation automatically. See `CLAUDE.md` for the rules every app follows.

## Run locally

```sh
npx serve .
```

Then open the address it prints, or add `/job-site/` for the trade calculators. The service worker (offline and install) needs `localhost` or HTTPS.

## Files

- `index.html`, `styles.css`, `app.js`: the app
- `manifest.webmanifest`, `sw.js`, `icons/`: PWA install and offline support
- `job-site/`: the Job Site Calculator, with its own manifest, service worker, icons and `theme-config.js`
- `shared/`: storage and theme modules used by both apps
- `calculator.html`, `job-site/job-site-calculator.html`: preview builds for claude.ai, generated by `node scripts/build-artifact.mjs [job-site]`
- `scripts/render-icons.mjs`: regenerates the PNG icons from the SVGs (`node scripts/render-icons.mjs [job-site]`, needs Playwright)
